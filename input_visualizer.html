2. Button

Value of clickcount:

HTML Code
<button @click="clickButton()">Click Me!</button>

<p>Value of clickCount: <span x-text="clickCount"></span></p>
Alpine JS Method
clickButton() {
  this.clickCount++;
}
3. Checkbox

Value of statusText:

HTML Code
<!-- @click can also be used with checkboxes. -->
<label>
  <input type="checkbox" x-model="isChecked" @change="updateStatus()"> Toggle Message
</label>

<p>Value of statusText: <span x-text="statusText"></span></p>
Alpine JS Method
updateStatus() {
  if (this.isChecked) {
    this.statusText = 'Checked';
  } else {
    this.statusText = 'Not Checked';
  }
}
